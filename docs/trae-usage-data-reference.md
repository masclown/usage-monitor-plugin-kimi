## 0. 关键特点：开发者行为分析型 dashboard

不同于其他站的"配额进度条 + 消耗明细"，TRAE 的 dashboard 主打**开发者行为可视化**：
- IDE 活跃天数热力图、代码采纳次数、对话次数、编程时段分布、模型调用偏好、最佳拍档（Agent）
- 用量明细（时间/产品端/模型/消耗次数/权益来源）在独立的"用量管理"页

### 与其他站对比

| 维度 | MiniMax | Kimi | Qoder | WorkBuddy | TRAE |
|---|---|---|---|---|---|
| 定位 | 配额+趋势 | 配额+明细 | 配额+明细 | 配额+运营 | **行为分析+明细** |
| 主题 | 浅 | 深 | 深 | 浅 | **深 #1A1B1D** |
| 接口鉴权 | Cookie | Bearer | Cookie | Cookie | **字节签名(msToken)** |
| 热力图 | 红透明度 | 无 | 无 | 绿(月历+年) | **绿实心(#0FDC78/#32F08C)** |
| 特色维度 | 缓存命中率 | Code/Kimi | 折扣 | 能量/连登 | **代码采纳率/编程时段/模型偏好** |

## 1. 基础信息

- **仪表盘 URL**：`https://www.trae.cn/dashboard#dashboard`
- **用量管理**：`https://www.trae.cn/dashboard#usage`
- **API 域名**：`https://api.trae.cn`
- **鉴权**：Cookie + **字节签名参数**（msToken/ttwid，直接调接口需签名，空 body 返回 500）
- **登录跳转链**（实测）：
  ```
  /dashboard#dashboard（未登录）
    → /login?redirect_url=.../dashboard#dashboard
    → 手机号+验证码 / 抖音 / 苹果 / 企业账号 / 稀土掘金
    → 回跳 /dashboard#dashboard
  ```

## 2. 接口清单（api.trae.cn，POST）

| 接口 | 用途 | 说明 |
|---|---|---|
| `/cloudide/api/v3/trae/GetUserStasticData` | 统计数据（热力图/采纳/对话/模型偏好）| ⚠️ 需签名参数 |
| `/cloudide/api/v3/trae/GetUserInfo` | 用户信息 | 🔴 可能含敏感，脱敏 |
| `/cloudide/api/v3/trae/CheckLogin` | 登录态检查 | — |
| `/cloudide/api/v3/common/GetUserToken` | 用户 token | 🔴 敏感，不入库 |
| `/trae/api/v2/pay/user_current_entitlement_list` | 订阅权益/配额 | 需签名参数 |

> ⚠️ **字节系接口签名**：TRAE 接口需 `msToken`（mssdk.bytedance.com 生成）+ `ttwid` 等签名参数，直接 `fetch` 空 body 返回 500/1001（authenticate failed）。数据实际随页面加载已渲染，**从 DOM 提取更可靠**。

## 5. 视觉样式 + 交互（实测 computed style）

### 主题
- 页面背景：**深色 `#1A1B1D`**（rgb 26,27,29）
- 品牌绿：登录按钮 + 高亮元素为绿色系

### 活跃热力图配色（GitHub 式，SVG rect）
**绿色系 + fill-opacity 分档**（实测：同色 `#32F08C` + 不同透明度，非多色值）：
| 档 | 颜色 |
|---|---|
| L0 无活动 | `#EDEFF2`（浅灰）|
| 中 | `#0FDC78`（中绿）|
| 高 | `#32F08C`（亮绿/荧光），通过 `fill-opacity`（0.75 等）调深浅 |
| 灰态 | `#8D93A6` |
- 格子：13px SVG rect，`rx=2`（圆角）；图例：`Less → More`
- ★ **格子 hover tooltip（实测）**：`06 月 27 日 使用 AI 功能 7 次`——悬停显示**日期 + 当日使用 AI 功能次数**（用户确认）

### 模型调用偏好（横条）
- 深色槽 + 渐变横条，右侧数字（如 deepseek-V3.1 70 / glm-4.7 60）
- ★ **hover tooltip（实测）**：`累积使用 glm-4.7 60 次`——显示**累积使用 某模型 N 次**

### 最佳拍档
- @Code Reviewer，静态显示“配合次数 70”（某时间范围内与某 Agent 的配合次数，如用户例 Code Reviewer 72 次）

### 编程时段弧形图
- 半圆弧线 + **24 个数据点圆**（10→次日，对应 24 小时），每个圆 `fill-opacity`（0.25/0.5/0.75/0.92）表达该时段活跃度；太阳/月亮图标标日夜时段
- ★ **数据点 hover tooltip（实测）**：`7 月 17 日 - 7 月 23 日 近期有 4 天在 16:00 工作`——显示**时间范围 + 该时段工作天数**

### 交互总结（用户重点）
四个图表都有 hover tooltip，且多带**时间范围**（如 7月17日-7月23日）：
| 图表 | hover 显示 |
|---|---|
| 活跃热力图格子 | `日期 + 使用 AI 功能 N 次` |
| 模型偏好横条 | `累积使用 模型 N 次` |
| 编程时段数据点 | `时间范围 + 近期有 N 天在 X:00 工作` |
| 最佳拍档 | 配合次数（时间范围内）|
> ★ SDK 启示：图表 hover tooltip 应支持“维度值 + 时间范围 + 业务文案”的组合（不只是裸数字）。

### 横条图（代码采纳/模型偏好）
- 深色槽 + 数值横条，右侧数字标注

### 编程时段弧形图
- 半圆弧线 + 圆点（时段活跃度），太阳/月亮端点图标

### 对 SDK 的启示
- TRAE 热力图 = **绿色系实心多档**（#0FDC78/#32F08C）→ 又一个"多色阶实心"样本，与 WorkBuddy 年视图同类
- **编程时段弧形图**是全新图表类型（时段分布），SDK 图表库可考虑扩展"时段/极坐标"类
- 深色主题（#1A1B1D）+ 荧光绿高亮 → SDK 深色主题色板参考

## 6. 对统一 SDK 的启示

1. **行为分析维度**（代码采纳率、对话次数、编程时段、模型偏好、最佳拍档、成就标签）——TRAE 独有，远超"用量数字"，属 **Provider 专属子表**，不进 SDK 通用字段。
2. **模型偏好**（模型×调用次数排行）与 WorkBuddy 明细的 model 维度、Qoder 的 model_category 呼应——SDK 可有"模型维度用量"通用支持。
3. **字节签名鉴权**——四站里最复杂（Cookie+msToken+ttwid），插件抓取需处理签名；或优先 DOM 提取。
4. **多种图表类型**：热力图 + 横条 + 弧形时段图——证明 SDK 图表库需可扩展（不止折线/热力）。
5. 🔴 **敏感**：GetUserToken、GetUserInfo 可能含 token/手机号，标 Sensitive 不入库。
